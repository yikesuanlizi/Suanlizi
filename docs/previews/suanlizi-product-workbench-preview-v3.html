使用说明

1欢迎使用 Suanlizi

Suanlizi 是一款 AI 原生的智能开发助手，集成多 Agent 协作、工作流编排、代码知识库、微信/钉钉对接等能力。

2核心功能概览

  • 多 Agent 协作：主控 Agent 与专业 Agent 协同完成复杂任务
  • 工作流项目：可视化编排 AI 工作流，支持条件分支和循环
  • GitNexus 代码分析：基于知识图谱的代码架构理解与智能搜索
  • 微信/钉钉对接：在群聊中直接调用 AI 能力
  • MCP 插件生态：通过 Model Context Protocol 扩展工具能力

3运行配置说明

缓存优先保持提示词和工具结构稳定，尽量延迟压缩，提高缓存命中率。
长运行优先保证长任务、多智能体、工具调用、压缩和中断恢复可追踪。
思考程度快速适合简单问答；均衡适合日常编码；深度适合复杂设计与排查。
权限模式只读禁止写入；默认按策略审批；自主权限更宽。
联网搜索自动模式仅在需要最新或外部信息时提示使用。
上下文压缩把旧轮次写成可追踪摘要，释放上下文窗口。

4GitNexus 代码分析

  • 概览：代码统计、依赖关系图和模块分布
  • 智能搜索：按自然语言描述检索相关代码
  • 符号上下文：查看定义、引用、依赖与调用链
  • 影响分析：评估修改某个符号的影响范围
  • 调用路径：追踪入口到目标符号的调用链
